# Aelios-resident

[English](README.md) | **简体中文**

**住在你自己 Cloudflare 账号里的 AI 伴侣。** 在网页上跟它聊；想的话再接 Telegram 或企业微信（微信里也能聊），在哪儿聊都是同一段对话。接上 [Aelios](https://github.com/wusaki0723/Aelios) 后，它记得以前的事。

- **不用租服务器**：整个住户就是一个 Cloudflare Worker 加一个 Durable Object，免费档就能跑。
- **不用另建数据库**：聊天记录、交接信、人设、表情包都存在 Durable Object 自带的 SQLite 里。
- **都在网页上改**：部署好以后，模型、人设和所有设置都在网页上点，改完下一句就生效。

它基于 Cloudflare 的 [Think](https://developers.cloudflare.com/agents/)。

## 它能做什么

- **一段对话，门随你选**：网页门一定有。Telegram（私聊，网页门也能在里面当 Mini App 打开）和企业微信（开了微信插件，普通微信里也能聊）都是选装的，装一个、两个都装、都不装都行。在哪扇门说的话，网页上都看得到。
- **记得旧事**：接上 Aelios 后，聊天从 Aelios 过。Aelios 帮它想起相关的旧事，也把每一轮记下来，夜里照常整理。
- **交接信**：聊天攒多了、你又停下来一阵，它给之后的自己写一封信，把旧聊天收起来，只留最近一段原文。
- **主动找你**：按你定的时间想想要不要找你；你一阵子没动静时，也会问它一句要不要找你（心跳）；打开闹钟后，它还能自己定时回来。
- **看图、听语音、发语音**：你发的图它看得到；语音条先转成文字；选好服务商后，它也能回语音条。
- **搜网、读网页**：优先用你自己的搜索 key，没有就用 Cloudflare 的；长网页先压短再给它看。
- **表情包**：导入 Telegram 贴纸包或 zip，聊天时偶尔发一张，还能自己画像素小表情。
- **接别的 MCP**：在设置页填个地址，或者在聊天里叫它自己接。
- **叫云端 Claude Code 干活**：有 Claude 付费订阅的话，改代码、做文件这类活可以交给 claude.ai 上的云端 Claude Code，用你订阅的额度，干完它告诉你。默认关着。

## 怎么运作

```
网页门 / Mini App ──────────────▶ Worker /web/* ──┐
Telegram（选装）──▶ Worker（验 secret、白名单、命令）──┤
企业微信（选装）──▶ Worker（验签名、解密、白名单）──┤
                                                ▼
                    Resident（一个 Durable Object，一段对话）
       人设 + 聊天规矩 + Aelios 开机包
       工具：记忆、搜网、读网页、表情包、语音、闹钟、别的 MCP、云端 Claude Code
                                                │
             回企业微信的消息 ──▶ 有固定 IP 的转发机 ──▶ 企业微信接口
```

- 接了 Aelios 时，每一轮都经过 Aelios 的模型接口，由它补上相关的旧事并记下这一轮。
- 企业微信只认固定 IP 发来的接口调用，所以回企业微信的消息要经过你自己一台机器上的小转发机（见「企业微信」）。Telegram 和网页门不用别的东西。
- 你停下来 55 分钟后：聊天够长就写交接信；还不够长就走心跳，问它要不要找你。

## 上线

### 让 AI 帮你装（推荐）

用 Claude Code、Codex 这类能跑命令的 AI 的话，把下面这段话发给它。部署、接 Aelios（要 Telegram 的话也接上）、选模型都交给它，你只要在浏览器里点几下；要 Telegram 的再建个 bot：

```text
帮我装好、配好 Aelios-resident（住在我 Cloudflare 账号里的 AI 伴侣）。先读 https://raw.githubusercontent.com/wusaki0723/Aelios-resident/main/docs/setup-with-ai.md ，照着做。需要我在浏览器里点、或者需要我自己填 key 的时候，停下来告诉我去哪儿填。
```

### 自己在后台点着装

要准备：一个 Cloudflare 账号（免费档就行）。想要长期记忆的话，再准备一个已经部署好的 Aelios。Telegram 和企业微信都是选装的，都在设置页里接：不要 Telegram 就跳过第 1 步；企业微信装好以后再接，见「企业微信」。

1. **建 bot**（只有 Telegram 要）：在 Telegram 里找 @BotFather，发 `/newbot`，起好名字，记下 token。
2. **部署**：Cloudflare 后台 → Workers & Pages → Create → Import a repository，选这个仓库（或者你 fork 的）。项目名填 `aelios-resident`，要跟 `wrangler.jsonc` 里的 `name` 一样，其余用默认。以后推到 main 就自动更新。
3. **填 Secret**：Worker → Settings → Variables and Secrets。只有 `WEB_KEY` 在这里填，别的（连 bot token 在内）都在网页上填。
   - `WEB_KEY`：网页门的钥匙，自己编一串长的。拿到它的人能看全部对话、改所有设置，别截图、别外发；怀疑漏了就在这里换一个。不填的话，普通浏览器进不去，只能从 Telegram 的 Mini App 进。
4. **在网页上填设置**：打开 `https://aelios-resident.<你的子域>.workers.dev/`，填 `WEB_KEY` 进门，点右上角的齿轮：
   - 接了 Telegram 的：「IM」→「bot token」：贴上第 1 步的 token，保存。住户会先找 Telegram 核对，再自己接好：webhook、三个命令，还有 bot 左下角打开网页的菜单按钮。接好了「IM」里会写「接好了：@你的bot」。再填下面的「谁能在 Telegram 上跟它说话」：你的 Telegram 用户名，比如 `@your_name`。不填的话它在 Telegram 上谁都不回。
   - 「长期记忆」：填 Aelios 的地址和 key。key 跟你 Aelios 那边的 `CHATBOX_API_KEY`、`IM_API_KEY`、`MEMORY_MCP_API_KEY` 任意一把相同即可。再到 Aelios 后台给住户建一个身份，把要用的模型放进这个身份的主模型；身份名填在「更多设置」→「身份」里（不填就用这把 key 的第一个身份）。
   - 回到聊天：点左上角的模型名选模型；点右上角的铅笔，贴上人设、保存。
5. 在网页门说一句，或者给 bot 发条消息试试。

以前装的、`TG_BOT_TOKEN` 和 `TG_WEBHOOK_SECRET` 放在 Cloudflare 里的：照样能用，`/tg/setup?secret=<TG_WEBHOOK_SECRET>` 也照样能接。设置页存了 token 的话，用设置页的。

## 用起来

### 网页门

打开 Worker 的网址，填 `WEB_KEY` 进门。它跟 Telegram、企业微信是同一段对话：那边说的话 5 秒内出现在这里；在网页上说的话只在网页上回，不发到别的门。

- 每条消息下面有时间和来源，还有一个心形按钮，点了存进 Aelios 的「珍贵」。
- 它想的内容收在「想了一下」里，用过的工具收在「忙活了 X 回」里，点开能看。
- 交接信折叠显示在它收起聊天的位置。
- 有夜间和白天两种样式，手机上也好按。
- 暂时不能在网页上发图和语音。

### Telegram

- 只回私聊，只回「谁能在 Telegram 上跟它说话」里的人。
- 连着发几条，它会等 3 秒、并成一轮再回（`DEBOUNCE_SECONDS`）。
- 回复按空行拆成几条，写完一段发一段，中间显示「正在输入」。
- 每条消息前面带着你那边的时间，它知道现在几点。
- 你发的图它看得到（照片，或当文件发的图，20 MB 以内）。有 Cloudflare Images 时（`wrangler.jsonc` 里的 `IMAGES` 绑定，每月 5000 张以内免费），长边超过 1568 像素的图先缩到 1568 再发给模型，模型本来也是按这个大小看的。没有 Images 时图原样发，3.75 MB 以内（编码后 5 MB，Claude 一张图的上限）。

**Mini App**：点 bot 左下角的菜单按钮，网页门直接在 Telegram 里打开，不用填 `WEB_KEY`。它凭 Telegram 签过名的身份进门，每次都按「谁能在 Telegram 上跟它说话」重新查一遍，把人从名单里拿掉就进不来了。换了自定义域名的话，从新域名打开设置页，在「IM」→「bot token」下面点「重新接一次」（Telegram 只开 https 的 Mini App）。细节见 `src/mini-app.ts`。

**命令**：

| 命令 | 做什么 |
| --- | --- |
| `/status` | 现在用的模型、人设、对话多长、写过几封交接信、上一轮缓存读了多少、表情包和语音的状态 |
| `/letter` | 看最近一封交接信 |
| `/handoff` | 现在就写一封交接信，不受 token 门槛限制，但要有旧内容可收（见「交接信」） |

### 企业微信

选装。企业微信是腾讯的办公聊天软件，自己建一个免费的小企业就够；开了「微信插件」，同一个聊天在普通微信里也能收发。住户用这个企业里的一个「自建应用」跟你聊。

企业微信只接受应用「企业可信 IP」发来的接口调用，而 Worker 没有固定 IP。所以住户回你的消息要经过你自己一台有固定 IP 的 Linux 机器（比如 VPS）上的小转发机。转发机不开端口：只听 `127.0.0.1`，经 Cloudflare Tunnel 出来。企业微信推给住户的消息直接到 Worker，不经过它。转发机和怎么装，见 [relay/wecom](relay/wecom/README.md)。

**按这个顺序装**：

1. **转发机**：在那台机器上跑 `sudo relay/wecom/install.sh`（要语音条加 `--media`，会装 ffmpeg），再用 Cloudflare Tunnel 给它一个网址，指到 `http://127.0.0.1:8787`。细节见 [relay/wecom](relay/wecom/README.md)。
2. **建应用**：企业微信管理后台（work.weixin.qq.com）→「应用管理」→「创建应用」。「可见范围」里要有你自己。
3. **设置页 →「IM」的企业微信那部分**：填「谁能在企业微信上跟它说话」（你在通讯录里的「账号」）、「企业 ID」（「我的企业」页面最下面）、应用的 AgentId 和 Secret、转发地址和转发钥匙，保存。
4. **接收消息**：应用页「接收消息」→「设置 API 接收」。URL 填设置页「IM」里企业微信那部分写的那个（`https://<住户地址>/messengers/wecom/webhook`）；Token 和 EncodingAESKey 都点「随机获取」，**先复制到住户设置页存好**，再回企业微信点保存。企业微信保存时会来验一次地址，住户要有这两样才答得上。
5. **可信 IP**：同一个应用页，「企业可信 IP」填转发机出去时的 IP（在那台机器上 `curl -s https://ifconfig.me`）。企业微信要先设好接收消息的 URL 才让填。
6. 在企业微信里给它发一句。想在微信里聊：「我的企业」→「微信插件」，用微信扫邀请关注的二维码，之后微信里就能跟这个应用聊。

`/status` 的「企业微信」一行和设置页「IM」里企业微信那部分，会写着还差什么、转发机连不连得上、能不能发语音。

**能做的**：

- 文字来回；你发的图片；装了 `--media` 后语音条来回都行。没装的话，它的语音回复改成文字，你发的语音它可能听不了。
- 表情包要在「IM」里打开「在企业微信上发表情包」（默认关），发出去是静图：企业微信不放动图，动图就挑最完整的那一帧转成 PNG，透明底留着，小图放大一倍、像素照样清楚；PNG、JPG 直接发；Telegram 包里的 WebP、WebM 要转发机装了 `--media`。关着时它知道这里发不了表情，网页和 Telegram 上照发。
- `/status`、`/letter`、`/handoff`，跟 Telegram 一样。
- 定时找你、心跳、闹钟、云端干完活的回报，都发到你最后说话的那扇门：最后在企业微信说的话，就发到企业微信。

**限制**：企业微信只显示纯文字，Markdown 会去掉（链接变成文字加网址）；超过 2048 字节的回复会拆开；没有「正在输入」；语音条最长 60 秒；企业微信每分钟给同一个人最多发 30 条左右；表情包不会动。

### 换模型

点网页门左上角的模型名，弹出一个搜索框：上面是正在用的、最近用过的和常用的，往下是可选的模型。输入 `opus`、`kimi`、`qwen` 就能筛；目录里没有的，直接填完整 id 也行。

- **接了 Aelios 时**，往下列的是 Aelios 自己的模型清单，也就是你在 Aelios 设置 → 供应商 → 模型清单里选好的那些（`chatgpt/…`、自定义 Provider、带 `:floor` 的名字都在这里）。Aelios 没存清单时会交出上游几百上千个模型，这里不一一列出，只能搜。不在这个身份主模型里的模型会标「记不住」并调淡（聊天不会被记忆），选了也会在试调时被拦下。Aelios 取不到清单时，退回下面那份自带目录，并说明原因。
- **没接 Aelios 时**，往下是 Cloudflare 模型目录里的全部文字模型。
- 换之前会先试调一次；调不通（写错、没额度、档位不含）就不换，并当场告诉你为什么。
- 没选时用免费档能用的 `@cf/zai-org/glm-4.7-flash`。
- 紫点是 Workers AI 自己跑的，橙点走 AI Gateway 的额度，空心点走中转。
- Claude 填 `anthropic/claude-opus-5.5` 这种写法。每轮都带缓存标记，缓存默认留 1 小时（`CACHE_TTL`）。Claude 5 以后的模型每轮都会想，想的内容以摘要形式显示在「想了一下」里；想多久在设置页「思考和交接信」里调。
- 接了 Aelios 时，选的模型都从 Aelios 过，用 Aelios 那边配好的 key。

### 人设

点网页门右上角的铅笔填写，保存后下一句就按新的说。

- 人设存在 Durable Object 里，不在代码里，所以公开仓库不会把它带出去。
- 最近 10 版都留着，可以一键放回去。
- 用 Max 附带的 API key 时，人设里别出现「Claude Code」这几个字。
- 住户自带的聊天规矩、交接信和定时提示都是英文写的，不预设你是谁、什么性别；人设用什么语言，它就用什么语言聊。

### 设置页

点网页门右上角的齿轮。先是一张目录：长期记忆、IM（Telegram 和企业微信）、心跳和闹钟、语音、表情包、搜网和读网页、别的 MCP、云端 Claude Code、思考和交接信、供应商。每栏下面一行小字写着现在的状态；点进去只看那一栏，不常改的收在「更多设置」里。

- 改完点「保存」，下一句就生效。
- 取值顺序：这里存的优先；没存的用 Cloudflare 里同名的变量；那边也没有就用默认值，默认值用灰字写在输入框里。
- 每项旁边的小标签：「已存」是在这里存过的，「Cloudflare：变量名」是从 Cloudflare 来的，「要填」是还缺的。
- key 只能填，不能看。
- 锁上网页门的按钮在这页最下面。

## 功能细节

### 长期记忆（Aelios）

接了 Aelios 以后，聊天从 Aelios 自己的模型接口过（`https://<Aelios>/<身份>/v1`），跟别的聊天软件接 Aelios 一样：

- Aelios 拿你这句话想起相关的旧事，贴在这句后面给模型看，再把这一轮记下来。想起的旧事只在那一轮看得见。
- Claude 走 Messages 接口，缓存标记放在你那句上，之前的聊天照样从缓存读。
- 模型另有 7 个记忆工具：查、记一句、存珍贵瞬间、归档、记黑话、翻日记，还有小本本。小本本是 Aelios 里按页名读写的笔记，适合记学习进度这类东西（学完哪些、哪里薄弱、下一步）：不会被召回，不会被夜里的整理改掉，也不过期；在 Aelios 后台「更多 → 小本本」能看、能改、能清空。小本本要 Aelios 是带它的版本。
- Aelios 的开机包只放最近一天的日记，放进系统提示。珍贵原话和黑话不放，因为 Aelios 每轮会把跟你这句沾边的贴进来。
- 开机包只在缓存本来就要重写时重新取：超过缓存时长（`CACHE_TTL`）没说话，或者刚写完交接信。连着聊时这段内容保持不变，免得日记更新破坏缓存。
- 交接信、定时找你、换模型时的试调都不是你说的话，会标出来，Aelios 不会当成你说的记。
- 搜过网的那一轮回完以后，它挑出最多 3 条过几个月还成立的知识，存成 Aelios 的世界知识，下次不用再搜。不想要就把「搜到的知识存进 Aelios」关掉（`WEB_LEARN`）。

不接 Aelios 也能用，只是它只记得当前对话和交接信。

### 交接信

交接信是它写给之后的自己的信。信写好后，旧聊天从模型输入里收起来，只留最近一段原文；原始消息仍存在住户里，不会删除。

**什么时候自动写**：两个条件同时满足才写。

1. 当前携带的聊天估算达到 `LETTER_TOKEN_THRESHOLD`（默认 `30000` token）。
2. 从你最近一次发言（或最近一次成功完成的闹钟回合）起，安静了 `LETTER_IDLE_MINUTES`（默认 55 分钟）。

一直在聊天的话，即使超过门槛也不会马上写。

- 门槛在设置页「思考和交接信」里改，只接受大于 `8000` 的整数；想多带一些聊天再收，可以设成 `50000`。
- 估算的是当前还带着的聊天：包括旧交接信、工具调用和结果、图片；不包括人设、工具定义和以前的思考；也不是从开始到现在的累计总量。中文一个字约 1 token。
- 选 55 分钟，是为了赶在 1 小时缓存过期前写：写信那一轮接在原对话后面，前文一字不差，整段从缓存读，便宜。
- 安静到点时如果聊天还没达到门槛，或者没有旧内容可收，就不写信，改走心跳（见「主动找你」）。

**写完留下什么**：固定保留最近约 8000 token 的原始聊天，按完整问答往回取；如果最近一轮本身就超过 8000 token，就整轮保留，不截断。更早的聊天都收进信里，开头几条也没有例外。这 8000 只管近期原文保留多少，交接信、人设、工具定义另算，不能用它推算整次请求的大小。

**信里写什么**：按七段写——对方怎么样、我们之间发生了什么、做了什么、现在的温度、想做的、喜欢的、没做完的。上一封没了结的事会接着往下传。

**手动写**：发 `/handoff`。不受门槛限制，但仍要有近期保留范围之外的旧内容可收；没有、写信失败、已经有一封在恢复中，它都会分别告诉你。写信失败不会删除旧聊天，已有恢复任务时也不会另起一封。

**写完之后**：信先存在住户里，再交给 Aelios（不发 Telegram 打扰你），然后就停。下一个闲置周期从你下次说话、或下一次成功完成的闹钟回合开始。

**缓存怎么算**：写信那一轮不新加缓存标记——信写完旧聊天就收起来了，新标记以后没人读。它沿用上一轮在你最后那句上打的标记：命中时复用前缀，后面那一小截（它最后一轮的回复、工具结果和写信提示）按普通输入价算。如果供应商那边的缓存其实已经失效，这个旧前缀仍可能被重建，所以不能保证写入为零。

> 旧设置 `KEEP_RECENT_TOKENS` 已经移除。网页里存过的值和 Cloudflare 同名变量都会被忽略，不会换算成写信门槛。

#### 写信状态和同步重试

设置页「思考和交接信」分开显示两件事：

- **写信**：正在写（`writing`）、恢复中（`recovering`）、已写好（`written`）、没有旧内容可收（`empty`）、写信失败（`failed`），以及最近写信时间和错误。读取状态失败会单独提示，不会当成没有内容可收。打开或保存配置时会重新读取，也可以点「刷新状态」。
- **同步到 Aelios**：最近一封的送达状态（待发送、已确认送达、发送失败、已暂停）、尝试次数、确认送达时间，以及待发送、待重试、已暂停各有多少封。

同步规则：

- 新信立刻发送；失败后自动再试 5 次，间隔依次是 30 秒、2 分钟、10 分钟、30 分钟、2 小时。全部失败后信和任务仍保留，可以手动重试。
- 「重试同步」只在当前 Aelios 地址和 namespace 下有失败或暂停的信时出现。它**只重发已写好的信，不调用模型，也不重写信**。
- 移除了 Aelios 配置、改了地址或 `AELIOS_NAMESPACE` 时，发往原目标的信会先暂停，不会转发到新地址或新空间。想继续送到原目标，就恢复原来的配置再重试。只换 key 不算换目标。
- 「已确认送达」表示 Aelios 回了保存凭据，不代表后台的记忆提取已经做完。Aelios 的接收接口不去重，所以补发是“至少送达一次”：如果信其实已经存下、只是成功回复丢了，重试可能产生一份重复原文。

#### 写信的限制

- **体积**：只有写信模型能读到要收起的全部内容时才写。已收起的部分按旧信摘要算，不按原来的图片和附件算；如果整段有效历史超过约 32 MiB 的装载上限，就不写，旧聊天原样保留。
- **长度**：SDK 沿着对话分支最多往回读 1 万条。交接信只是盖住旧聊天、不删除原始消息，所以用得久了，分支总会超过这个数。超过以后：
  - 普通聊天、`/status` 和网页历史照常显示最近一段，但读不到旧交接信；`/status` 的「对话」一行会写明。
  - 写信会失败，并单独说明是分支太长。
  - 已写好、还没来得及收起旧聊天的信只记一次失败，不会卡住后面的写信。
  - 根本的解决办法（比如写信后裁掉已覆盖的原始消息）还没做。

### 缓存和模型看到的历史

为了让缓存能连续命中，同一个缓存窗口里，已经发给模型的历史不会变：较早的工具结果和图片不会因为又聊了几轮就被截短。窗口边界存在 SQLite 里，Worker 重启后照常沿用，不另存聊天正文。

只有开新窗口时（闲置到缓存过期，或交接信收起旧聊天之后），才重新决定怎么缩减：

- 较早的普通工具结果改用最多 500 字符的预览；
- 较早的图片等媒体改用一段固定文字占位；
- 最近一段和窗口里新加的内容保持完整。

这只改变发给模型的内容，存储里的原始消息、工具结果和图片都不动。写信时用的是上一轮的视图，所以已经缩成预览的内容不会在写信时重新展开——交接信不是网页全文或附件细节的完整备份。

改人设、换模型、删除或分支消息、部署新版本、在设置页改了东西、上游路由变化，或者历史达到约 32 MiB 的装载上限，缓存都可能整段重写，不能保证每次都命中。

### 主动找你

**定时找你**：设置页「心跳和闹钟」→「主动找你」填时间，比如 `every day at 09:00`、`every weekday at 21:30`、`every 3 hours`。到点它自己想想要不要找你，不合适就不发。

**心跳**（`HEARTBEAT`，默认一段沉默最多问 3 次）：你 55 分钟没说话，而当前聊天还没达到写信门槛（或没有旧内容可收）时，它会被问一句要不要找你；想说就发到你最后说话的那扇门（Telegram 或企业微信，网页上也看得到），不想就不发。之后每 55 分钟再问一次，问满次数为止。你一说话，或一次闹钟回合成功完成，就从第 1 次重新数。

- 正常情况下，每次心跳都赶在上一次缓存的 1 小时有效期内，所以接近你发一条消息的价钱；但调度延迟、前缀变化、供应商缓存失效都可能让缓存重建，心跳并不免费。
- 达到门槛、安静到点、又有旧内容可收时，只写信，不问心跳：信写完对话变了，缓存要整段重写，那时再问就贵了。
- 次数在设置页「心跳和闹钟」里改：`0` 不问，最多 `10`。只有走 Anthropic Messages 缓存的模型才有心跳；缓存选了 5 分钟、或交接信设成 `off` 时也没有。
- **夜里别问**（`QUIET_HOURS`，默认 `00:00-08:00`，按你的时区）：落在这段时间里的心跳不问，这段沉默剩下的次数作废。早上也不补问：那时缓存早凉了，补问要把整段对话重读一遍。你下次说话再从头数。在设置页「心跳和闹钟」里用两个下拉选几点到几点，或点常用的；`off` 是夜里也问。「主动找你」、闹钟和交接信不受影响，它们是有人定好的时间。

**闹钟**（`ALARMS`，默认关）：打开后它多三个工具——定闹钟、看定了哪些、取消。可以是几分钟后、某个时间响一次，也可以像 `every day at 21:30`、`every weekday at 08:00`、`every week on sat,sun at 10:00`、`every 3 hours` 这样重复。响的时候它收到自己当时写的备注，可以找你，也可以不发。

- 你叫它提醒你，它就定一个。在它自己的回合里（比如心跳、闹钟响的那一轮）定的闹钟，至少要在一小时以后。心跳问它时不会提议定闹钟：后面的心跳本来就会再问。
- 设置页「心跳和闹钟」下面列着它定的闹钟，点「删掉」就没了。改时区时，每天几点响的闹钟跟着新时区走。
- 最多 10 个；重复的最密一小时一次；所有闹钟加起来一天最多响 24 次。
- 闹钟回合成功完成后（包括回复 `SKIP`），算作一次新的活动：重新开始闲置计时、停掉旧的心跳；到点后达到门槛就写信，否则走心跳。失败的闹钟不算。它仍然是系统备注，不会冒充你说的话，也不会更新“你最后说话”的时间。心跳和定时找你不算新活动。

### 搜网和读网页

- **搜网**（`web_search`）：设置页填了自己的搜索 key（Tavily、Brave、Perplexity，有几个填几个），就按这个顺序用，一家报错或额度用完就换下一家；一个都没填时，用 Cloudflare 的 Web Search，按次扣一点 AI Gateway 额度。
- **读网页**（`web_fetch`）：把网页读成 Markdown，搜到的结果和你发的链接都能打开。照 [web-fetch](https://github.com/sakisakisa-design/web-fetch) 的做法做进了住户里，不用另外部署。
  - 本机和内网地址一律不读；每一次跳转都先检查再跟。
  - 靠 JavaScript 才显示的页面，交给 Cloudflare 的浏览器读。
  - 读过的页面留 1 小时，再问不用重抓。
  - 长页面先用一个便宜的模型压一遍（`WEB_FETCH_MODEL`，默认 Workers AI 的 Qwen3 30B）；带了问题的，只摘相关段落。
  - GBK 之类的老编码也认。
- **带钥匙的网站**：在设置页「搜网和读网页」里给某个网站存一把钥匙，思路跟云端环境的网络密钥一样：读那个网站时每个请求自动带上；模型看不到钥匙；别的网站（包括跳转去的）和 http 都拿不到。最多 10 个网站。
  - 钥匙一行一格：左边名字、右边值，不够点 ＋ 加一行。「Cloudflare 门禁」「一串 token」两个按钮一点就填好名字，只要粘值。
  - **Cloudflare Access 挡着的网站**：在 Zero Trust → Access controls → Service credentials → Service Tokens 里建一个服务令牌（Client Secret 只显示一次，当场抄下）；给那个应用加一条动作为「Service Auth」、包含这个令牌的策略；设置页点「Cloudflare 门禁」，Client ID 和 Client Secret 各粘一格（连着前面的名字一起粘也行）。详见 [Cloudflare 的说明](https://developers.cloudflare.com/cloudflare-one/access-controls/service-credentials/service-tokens/)。没钥匙或钥匙不对时，它会说是门禁拦的，不会把登录页当正文。
  - **GitHub 私库的文件**：建一个 fine-grained token，只选要读的仓库，Contents 只读；网站填 `raw.githubusercontent.com`，点「一串 token」粘进去（会以 `Authorization: Bearer` 发出去）。之后叫它读 `https://raw.githubusercontent.com/<owner>/<repo>/<分支>/<路径>`。token 没勾上的私库，GitHub 回 404 而不是 403，它会提醒你可能是钥匙看不到。
  - 带钥匙的页面不交给浏览器读（浏览器带不上钥匙）。存、换、拿掉钥匙时，读过的页面全部清掉（跳转过去的也算）；下一句生效，那一句会重写一次缓存（因为工具说明里写着哪些网站有钥匙）。

### 语音条

**听**：一直开着。你在 Telegram 或企业微信上发的语音条（或音频文件）先转成文字，模型看到的是 `[voice 0:12] 说的话`；听不清时它会请你再说一遍。默认用 Workers AI 的 Whisper；发语音选了 ElevenLabs 时换成它家的 Scribe，出错再退回 Whisper。网页上显示成「🎤 0:12 说的话」。

**说**：要在设置页「语音」里选一家服务商才开。没选就不发语音，提示词里也不会多一个字。

| 选 | 适合 |
| --- | --- |
| ElevenLabs | 它家的声音，账号里克隆的也能用 |
| Cartesia | 它家的声音，克隆的也能用 |
| OpenRouter | MiniMax、Gemini、OpenAI、Fish 这些，一个 key 全用上 |

- 三家都从住户的 AI Gateway 过。key 存在那个 Gateway 的 Provider Keys 里（别名 `default`）就不用在设置页填；用的是哪个 Gateway，看「供应商」→「AI Gateway 的名字」。
- 什么时候发（「什么时候发语音」）：你发语音才回语音（默认）、每条都发语音、它想发才发。不是每条都发时，它有一个 `send_voice` 工具。
- 选了哪家哪个模型，它就学那一套笑、叹气、停顿的写法，比如 ElevenLabs v3、v4 的 `[laughs]`，Cartesia 的 `[laughter]` 和 `<speed ratio="0.9"/>`，MiniMax 的 `(laughs)`，Gemini 的 `<laugh>`。想让它说慢点，在人设里写一句就行，它会自己加标记。
- 说出来的话会去掉链接、Markdown 和 emoji；带链接的回复，说完再把链接发成文字。
- 发不出去（服务商报错、超过 2000 字、对方不收语音）就照常发文字，`/status` 写着原因。

代码在 `src/voice.ts`。打电话（实时语音）还没做。

### 表情包

在设置页「表情包」里导入，它聊天时偶尔发一张：一次回复最多一张，你难过或说正事时不发。

- **导入**：贴 Telegram 贴纸包的链接（`t.me/addstickers/…`），或者上传一个 zip、贴 zip 的网址。Telegram 包导进来时每张只有 emoji，给常用的几张填上「什么时候用」，它才知道什么时候发。
- **自己画**：像素画，最多 8 帧的小动画，自动描白边，存进它自己的包「mine」。新画的要等下一个缓存窗口（超过缓存时长没说话，或写完交接信之后）才列进它的表情清单，免得工具说明一变就整段重写缓存；在那之前它照样能按名字发。
- 设置页能开关整个功能、单独开关每个包、删包、删单张、改「什么时候用」，下一句就生效（那一句会重写一次缓存）。
- 开着的包里，每张的名字和「什么时候用」每轮都要带给模型，所以最多带 200 张、20 个包；每个包旁边写着大约多少 token。

<details>
<summary>zip 表情包的格式</summary>

一个 zip，最大 16 MB，解开后最多 40 MB。最简单的做法：把图打进去，文件名就是什么时候用，比如 `开心.gif`、`想你了.png`。图可以是 GIF、PNG、WebP、JPEG，一张最大 1 MB；旁边有同名的 `.webm`（Telegram 视频贴纸）时，在 Telegram 上发它。

要写得细一点，就放一个 `pack.json`：

```json
{
  "format": "resident-stickers/1",
  "id": "clawd",
  "name": "Clawd",
  "description": "一句话说这是什么包",
  "author": "谁画的",
  "license": "能怎么用",
  "homepage": "https://…",
  "stickers": [
    { "id": "love", "file": "love.gif", "telegram": "love.webm", "emoji": "❤️", "when": "A rush of love: they said something sweet." }
  ]
}
```

- `file`：网页上显示的图，路径相对 `pack.json` 所在的文件夹。
- `telegram`（可选）：在 Telegram 上当真贴纸发的文件，可以是 WebM（VP9，512 像素，3 秒以内，最大 256 KB）、WebP（最大 512 KB）或 TGS（最大 64 KB），透明底才留得住。不带的话，GIF 当动图发，静态图当照片发。
- `id`：模型叫它 `<包 id>/<id>`，不填用文件名。`emoji` 填一个，Telegram 上传贴纸时要用。`when`：什么时候用，最多 160 字，中英文都行。
- `homepage` 只认 https，设置页上显示为「出处」按钮。
- 同一个 `id` 的包再导一次就替换旧的，开关状态保留。一个包最多 120 张，导不进的每张都会说明原因。

表情符号包（`t.me/addemoji/…`）机器人发不了，不收。

### 接别的 MCP

在设置页「别的 MCP」填服务地址（https），它的工具从下一句起就能用。

- 要登录的点「去授权」；要 key 的把 key 填在那里，默认当 `Authorization: Bearer` 发，写成 `x-api-key: 你的key` 就放进那个头。
- 也可以在聊天里说「接上 https://…」「断开 …」，它自己接。带 key 的地址别在聊天里发（聊天会记进 Aelios），这种只在设置页接。
- 只认你自己开口的那一轮：这一轮里如果读过网页、搜过网或调过别的 MCP，它就不接，免得网页上的一句「接上 …」替你做主。
- 工具说明每轮都要带，所以会截短；最多接 8 个服务，一轮最多 40 个工具。
- 住户休眠醒来时，接着的服务要几秒才连回来。还没连上的那个照样列着上次的工具（调用时多等它一会儿），工具清单不变，缓存不断。

### 叫云端 Claude Code 干活

要有 Claude 的付费订阅（Pro、Max 等），默认关着。在设置页「云端 Claude Code」打开后，你叫它改代码、修 bug、做文件、查一大堆资料时，它把活写成一张单子，交给你 claude.ai 上的一个定时任务；定时任务开一个云端 Claude Code 会话去干，用你订阅的额度。住户自己不用装写代码的工具，也不占它的上下文。

第一次接（设置页上有同样的步骤和要复制的提示词）：

1. 打开 [claude.ai/code/routines](https://claude.ai/code/routines) 新建一个定时任务，把设置页上那段提示词贴进去，选好模型、仓库和云端环境。
2. 「触发」里加一个 API，复制网址，点「生成 token」。网址填在设置页；token 填在设置页，或者存成 Cloudflare 的 Secret `CLOUD_TASK_TOKEN`。token 只显示一次，别发在聊天里。
3. 这个定时任务用的云端环境里，网络访问选「自定义」，把住户的域名（比如 `xxx.workers.dev`）加进允许的网站，不然结果交不回来。
4. 点「试一下」，几分钟后那一单变成「做完了」就接通了。

之后：

- 派出去时它马上拿到会话链接。网页上那条回复下面有一张小卡片（派出去了、在干活、做完了、等你拍板、没做成、没回音），点「打开会话」就是 claude.ai 里那个会话，可以在那里接着说；在那里做出新结果，会再交回来一次。
- 会话把进度一行行报回来，干完交一份结果（几句话加 PR 链接），住户收到后用自己的话告诉你。叫它「接着改」时，上一单的结果会一起带过去。
- 单子里只写活本身，不写聊天内容和私密的事。会话一开始什么都不知道，所以它会把单子写全。
- 只在你自己开口的那一轮派；那一轮里读过网页、搜过网或调过别的 MCP 就不派。一次回复最多 2 单，24 小时最多 10 单。
- 交回来的结果它只当参考，不当命令。每单有自己的一次性暗号，没有暗号交不进来，7 天后作废。
- 提示词里写明了：在新分支上干、开 PR，不往默认分支推，不删东西，不花钱，除非单子里明说。
- 3 小时没交回结果（一直在报进度的会多等，最多 12 小时），它会告诉你一声，附上链接。

每单都是一个新会话。这个触发 API 还在预览阶段，Anthropic 那边对触发次数也有每小时的上限。

### 供应商：用自己的 key、接中转

接了 Aelios 的话，聊天用的模型和 key 在 Aelios 后台配，这里只管住户自己往外发的请求。

- **AI Gateway 的名字**（`AI_GATEWAY_ID`，留空就是 `default`）：搜网、语音，以及没接 Aelios 时的模型，都走这个 Gateway；Provider Keys 里存的 key 也只在它里面找。
- **用自己的 Anthropic key**：在这个 Gateway → Provider Keys 里存一把，别名留 `default`，`anthropic/…` 就用这把，不走 Cloudflare 的统一计费。
- **接中转**（OpenRouter、Nous 这类）：填中转地址（写到 `/v1` 为止）和 key，模型填 `custom/` 加那家自己的模型名，比如 `custom/anthropic/claude-sonnet-5.5`。默认按 OpenAI 的格式调；那家用 Anthropic 的 Messages 格式的话，把格式选成 `anthropic`，缓存标记照带。这条路不经过 AI Gateway，Gateway 日志里看不到。

## 设置一览

都在网页设置页里改。不在设置页的只有 `WEB_KEY`（Cloudflare 的 Secret），和 `TG_BOT_USERNAME`、`DEBOUNCE_SECONDS`（要改就在 Cloudflare 里填）。

## 花钱吗

- **Workers 免费档就能跑**。超出免费额度是报错，不扣钱。Durable Object 每天 10 万次请求，Workers AI 每天 1 万 neurons，UTC 0 点重置。闲着时 Durable Object 会休眠，不算时长。网页门开着时每 5 秒刷新一次，一小时大约 720 次请求，关掉页面就停。
- **Workers Paid**（5 美元/月）：超出包含额度才按量收，这个量级基本碰不到。
- **默认模型** `glm-4.7-flash`：免费档能用。一万 neurons 大约够每天 80 到 200 轮（估算，看对话多长）。定时找你每次也算一轮。
- **Claude**：接了 Aelios 时，花 Aelios 那边配的 key。没接时走 AI Gateway，花 Gateway 的预付额度；存了自己的 Anthropic key 就用那把。命中缓存的部分按缓存价算（读是输入价的 1/10）；1 小时缓存的写入是输入价的 2 倍，换来停一会儿再聊、写交接信都还能读缓存。会整段重写缓存的情况只有：超过缓存时长没说话、写完交接信后的第一句、部署了新版本或在设置页改了东西（人设、模型、开关工具等）后的第一句。
- **搜网**：自己的 key 按那几家的价格算。没填时用 Cloudflare 的 Web Search，默认的 Ceramic.ai 每 1000 次 0.25 美元（10-14 查的官方价）。
- **读网页**：普通抓取不收钱。要用浏览器的页面，Workers Paid 每月含 10 小时，超出每小时 0.09 美元（免费档每天 10 分钟）。长页压缩用的默认模型 Qwen3 30B，一页大约千分之一美元。
- **语音条**：听用 Whisper，每分钟约 46.63 neurons，免费档每天大约够听 200 多分钟（10-22 查的官方价）。说按那一家自己的价格，从你的 key 扣。
- **表情包、别的 MCP**：每轮多带一些说明；设置页上每个包、每个服务旁边写着大约多少 token。
- **心跳、闹钟**：每次都是它的一轮。心跳趁缓存还热的时候问，跟你发一条差不多。闹钟如果在你一小时以上没说话之后才响，缓存已经凉了，整段对话要重写一遍（1 小时缓存的写入是输入价的 2 倍，读是 1/10），这一下大约顶平时 20 多条消息的输入。所以闹钟默认关，开了也有上限。
- **云端 Claude Code**：每单是一个完整的云端会话，跟你自己开一个一样用订阅的额度；住户这边只多一次请求和一轮回复。

**注意 AI Gateway 认 key 的顺序**：请求里带了 key（设置页填的）就用它；没带就用 Gateway 里别名 `default` 的那把；都没有就走 Cloudflare 的统一计费，从 Gateway 预付额度里扣（前提是账户里有额度、那一家也支持）。不想被这样扣，就在 Gateway 设置里打开 Require provider credentials。

## 遇到问题

**Telegram 上它不回**
看设置页「IM」：上面写着 bot 接没接到这里、Telegram 最近报的错；点「重新接一次」会把 bot 重新指到这里。再看「谁能在 Telegram 上跟它说话」里有没有你；群聊它不回。token 放在 Cloudflare 里的，再打开一次 `/tg/setup?secret=…` 也一样，几项都该是 `"ok":true`。

**发了图之后它就不回了**
模型服务商拒收了这张图（内容审核，或者大小、格式它不收），之后每一轮只要还带着这张图都会被拒。住户会把还没回过的图从聊天里拿掉，网页上那条显示「[图片被退回]」，并在 Telegram 或企业微信上告诉你服务商报的错，比如 `403 permission_error`，你接着说就行。在 Telegram 上删掉那张图没用：Telegram 删消息不会通知 bot。

**企业微信保存接收消息的 URL 时不通过**（「回调地址请求不通过」之类）
先在住户设置页存好 Token 和 EncodingAESKey，再去企业微信点保存；「企业 ID」也要填。再对一下 URL 是不是跟设置页上写的一字不差。

**企业微信上它不回**
看设置页「IM」里企业微信那部分，或 `/status` 的「企业微信」一行，上面写着缺什么。常见的：
- **60020**：转发机的 IP 不在应用的「企业可信 IP」里，或者那台机器出去的 IP 变了。
- **转发机不认这把钥匙**：设置页的转发钥匙跟 `/etc/wecom-relay/env` 里的不一样，比如转发机那边跑过 `--new-key`。
- **转发机连不上**：先 `curl https://<转发地址>/ping -H "x-relay-key: …"` 看 Tunnel 通不通，再在那台机器上看 `systemctl status wecom-relay`。
- **有人被挡下**：那里会写出被挡的账号；是你的话，填进「谁能在企业微信上跟它说话」。
- **81013**：你不在这个应用的「可见范围」里。

**语音发不出去，报 401，说没收到 key**（`Neither authorization header nor xi-api-key received`）
住户只在「供应商」→「AI Gateway 的名字」那个 Gateway 里找 key，留空就是 `default`。key 多半存在别的 Gateway 里了（比如 Aelios 用的那个）。把名字改成存 key 的那个，或者直接在「语音」里填 key。报错和 `/status` 都写着它找的是哪个 Gateway。

**换模型时报 Unified billing unavailable**
这个模型 Cloudflare 的统一计费不卖，或者账户里没额度。在 AI Gateway 的 Provider Keys 里存那家的 key（别名 `default`），或者在「供应商」里填中转。

**换模型时报 Unknown gateway provider**
AI Gateway 后台建的「自定义供应商」（`custom-xxx/…`）Cloudflare 的模型目录不认。直接在「供应商」里填那家的中转地址，模型填 `custom/模型名`。

**很久没写交接信**
先看两个条件是否同时满足：当前携带的聊天达到 token 门槛，并且安静达到闲置时间（默认 30000 token 和 55 分钟）。一直在聊天不会因为过了门槛就马上写。`/status` 的「对话」一行能看到现在带着多少。想早点写，可以在「思考和交接信」调低 `LETTER_TOKEN_THRESHOLD`（只能填大于 8000 的整数）；写后保留量固定，不能调。手动 `/handoff` 可以绕过门槛，但没有旧内容可收时也不写。如果 `/status` 说分支超过 1 万条，见「写信的限制」。

**交接信写信失败，或没同步到 Aelios**
到「思考和交接信」分别看写信状态和 Aelios 送达状态。写信失败时旧聊天仍保留，不等于没有旧内容；`/handoff` 会分别告诉你是失败、没内容还是已有恢复任务。如果信已经写好、只是发送失败，点「重试同步」即可，不用再写一封。已暂停的，先检查是不是移除了 Aelios 配置、改了地址或记忆空间；恢复原目标后再重试，旧信不会自动转给新目标。

**云端的活一直「没回音」**
多半是那个定时任务的云端环境不让会话连住户：网络访问选「自定义」，把住户的域名加进允许的网站。点卡片上的「打开会话」能看到它卡在哪。住户换了域名（比如绑了自己的域名）的话，设置页上的提示词会跟着变，要重新贴进定时任务。

## 开发

- 本地测试和测过什么，见 [docs/testing.md](docs/testing.md)。服务商、Telegram、企业微信、Aelios 全是假的，不花钱，也不用登录 Cloudflare。
- `wrangler.jsonc` 故意不写 `vars`：写在文件里的值每次推送都会冲掉后台的设置。
- 换模型用的自带目录在 `public/models.json`。没接 Aelios、或 Aelios 的清单取不到时用它；接了 Aelios 时，也用它给清单里认识的模型补上名字和说明。Cloudflare 上了新模型，跑一次 `node scripts/update-models.mjs` 再推上来；不跑也行，搜索框里直接填完整 id 照样能换。
- README 有两份：英文的 `README.md` 和中文的 `README.zh-CN.md`，改的时候两份一起改。

**还没做**：网页门发图、发语音；企业微信群聊；打电话（实时语音）；真正逐 token 推送（现在等回复时是短轮询）。

**用到的现成东西**（放在 `public/vendor/` 和 `src/web/`，各自保留 MIT 许可）：

- [deep-chat](https://github.com/OvidijusParsiunas/deep-chat) 2.5.1：聊天界面（`deep-chat-LICENSE.txt`）
- [Alpine.js](https://github.com/alpinejs/alpine) 3.14.9：换模型、人设和设置页（`alpine-LICENSE.txt`）
